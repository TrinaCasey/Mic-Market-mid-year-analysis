# MIC-Market-mid-year-analysis
A major supermarket MIC Market has had a $200 000 profit drop in the first half of 2026 compared to that of 2025 .  Using data collected from till transactions, POS machines, CCTV  reports, stock control and procurement departments, this is an analysis to figure out  the source of the drop  and ways to reduce the loss in the second half. of 2026.
